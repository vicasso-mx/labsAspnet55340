# Lab 03: Configuración de middleware y servicios en ASP.NET Core

## Escenario

Adventure Works quiere desarrollar un sitio web sobre deportes de pelota. Para conocer la popularidad de cada juego, necesita realizar una encuesta. Crearás el sitio de la encuesta.

## Ejercicio 1: Trabajar con archivos estáticos

La encuesta necesita una página HTML con estilos y un formulario que envíe los resultados al servidor.

Tareas: crear un proyecto ASP.NET Core Empty; ejecutar la aplicación; agregar un archivo HTML en `wwwroot`; comprobar que inicialmente no se muestra; habilitar archivos estáticos; comprobar que se muestra; agregar otro HTML fuera de `wwwroot` y comprobar que este no se muestra.

### Tarea 1: Crear un proyecto con la plantilla ASP.NET Core Empty

1. En la página de inicio de Visual Studio, selecciona **File > New > Project**.
2. En **Create a new project**, comprueba que el idioma seleccionado sea **C#**.
3. Selecciona **ASP.NET Core Empty** y haz clic en **Next**.
4. En **Project Name**, escribe `PollBall` y haz clic en **Next**.
5. En **Additional information**, selecciona **.NET 8.0 (Long-term support)**.
6. Comprueba que **Configure for HTTPS** esté desmarcado y deja las demás opciones con sus valores predeterminados.
7. Haz clic en **Create**.
8. En Visual Studio, selecciona **Debug > Start Without Debugging**.
9. En la barra de direcciones de Microsoft Edge, anota el puerto de `http://localhost:[port]`. Lo utilizarás durante el laboratorio.
10. Cierra Microsoft Edge.
11. En **Solution Explorer**, abre `Program.cs`.
12. Localiza:

    ```csharp
    app.MapGet("/", () => "Hello World!");
    ```
13. Reemplaza esa línea por:

    ```csharp
    app.Run(async (context) =>
    {
        await context.Response.WriteAsync("This text was generated by the app.Run middleware.");
    });
    ```

### Tarea 2: Ejecutar la aplicación

1. En Visual Studio, selecciona **File > Save All**.
2. Selecciona **Debug > Start Without Debugging**. **Nota:** El navegador mostrará `This text was generated by the app.Run middleware.`
3. Cierra Microsoft Edge.

## Ejercicio 2: Crear middleware personalizado

El servidor debe identificar el juego elegido por el usuario. Para ello crearás un componente middleware.

### Tarea 1: Crear el middleware

1. En **Solution Explorer**, abre `Program.cs`.
2. Localiza:

   ```csharp
   app.UseStaticFiles();
   ```
3. Antes de esa línea, agrega:

   ```csharp
   app.Use(async (context, next) =>
   {
       if (context.Request.Query.ContainsKey("favorite"))
       {
           string selectedValue = context.Request.Query["favorite"];
           await context.Response.WriteAsync("Selected value is: " + selectedValue);
       }
       else
       {
           await next.Invoke();
       }
   });
   ```

### Tarea 2: Ejecutar la aplicación

1. En Visual Studio, selecciona **File > Save All**.
2. Selecciona **Debug > Start Without Debugging**.
3. En Microsoft Edge, abre `http://localhost:[port]/poll-questions.html`.
4. Selecciona **Basketball** y haz clic en **Submit Poll**. **Nota:** El navegador mostrará `Selected value is: Basketball`, generado por `app.Use`.
5. Cierra Microsoft Edge.

### Tarea 3: Cambiar el orden del middleware

1. En **Solution Explorer**, abre `Program.cs`.
2. Selecciona:

   ```csharp
   app.UseStaticFiles();
   ```
3. Haz clic derecho en la selección y elige **Cut**.
4. Sitúa el cursor antes de:

   ```csharp
   app.Use(async (context, next) =>
   {
   ```
5. Haz clic derecho y selecciona **Paste**; después presiona **Enter**.
6. En Visual Studio, selecciona **File > Save All**.
7. Selecciona **Debug > Start Without Debugging**.
8. En Microsoft Edge, abre `http://localhost:[port]/poll-questions.html`.
9. Selecciona **Basketball** y haz clic en **Submit Poll**. **Nota:** La encuesta deja de funcionar: `UseStaticFiles` atiende la solicitud antes de que pueda ejecutarse `app.Use` y el navegador vuelve a mostrar `poll-questions.html`.
10. Cierra Microsoft Edge.
11. En `Program.cs`, usa **Ctrl+Z** hasta que `app.UseStaticFiles();` vuelva a estar después del bloque `app.Use`.
12. Selecciona **Debug > Start Without Debugging**.
13. En Microsoft Edge, abre `http://localhost:[port]/poll-questions.html`.
14. Verifica que la encuesta funcione de nuevo.
15. Cierra Microsoft Edge.

**Resultado:** Creaste un middleware personalizado para recibir los datos enviados por el formulario.

## Ejercicio 3: Usar inyección de dependencias

Necesitas reunir los votos y conservarlos para usos posteriores. Crearás un servicio que administre esos datos y lo registrarás mediante inyección de dependencias.

### Tarea 1: Definir una interfaz para el servicio

1. En **Solution Explorer**, haz clic derecho en **PollBall** y selecciona **Add > New Folder**.
2. Escribe `Services` y presiona **Enter**.
3. Haz clic derecho en **Services** y selecciona **Add > Class…**.
4. En **Name**, escribe `SelectedGame` y haz clic en **Add**.
5. En `SelectedGame.cs`, selecciona:

   ```csharp
   public class SelectedGame
   ```
6. Reemplaza la selección por:

   ```csharp
   public enum SelectedGame
   ```
7. Dentro del bloque `SelectedGame`, agrega:

   ```csharp
   Basketball,
   Football,
   Rugby,
   Volleyball,
   Billiards,
   Hockey,
   Golf,
   Tennis
   ```
8. Haz clic derecho en **Services** y selecciona **Add > New Item…**.
9. En **Add New Item -- PollBall**, selecciona **Interface**.
10. En **Name**, escribe `IPollResultsService` y haz clic en **Add**.
11. En `IPollResultsService.cs`, comprueba que la interfaz sea pública:

    ```csharp
    public interface IPollResultsService
    ```
12. Dentro de la interfaz, agrega:

    ```csharp
    void AddVote(SelectedGame game);
    SortedDictionary<SelectedGame, int> GetVoteResult();
    ```

### Tarea 2: Implementar el servicio

1. Haz clic derecho en **Services** y selecciona **Add > Class…**.
2. En **Name**, escribe `PollResultsService` y haz clic en **Add**.
3. En `PollResultsService.cs`, localiza:

   ```csharp
   public class PollResultsService
   ```
4. Agrega la interfaz a la declaración de la clase:

   ```csharp
   public class PollResultsService : IPollResultsService
   ```
5. Dentro de la clase, agrega:

   ```csharp
   private Dictionary<SelectedGame, int> _selectionVotes;

   public PollResultsService()
   {
       _selectionVotes = new Dictionary<SelectedGame, int>();
   }

   public void AddVote(SelectedGame game)
   {
   }
   ```
6. Dentro de `AddVote`, agrega:

   ```csharp
   if (_selectionVotes.ContainsKey(game))
   {
       _selectionVotes[game]++;
   }
   else
   {
       _selectionVotes.Add(game, 1);
   }
   ```
7. Después del método `AddVote`, presiona **Enter** dos veces y agrega:

   ```csharp
   public SortedDictionary<SelectedGame, int> GetVoteResult()
   {
       return new SortedDictionary<SelectedGame, int>(_selectionVotes);
   }
   ```

### Tarea 3: Usar inyección de dependencias

1. En **Solution Explorer**, abre `Program.cs`.
2. Localiza:

   ```csharp
   var app = builder.Build();
   ```
3. En la línea anterior, agrega:

   ```csharp
   builder.Services.AddSingleton<IPollResultsService, PollResultsService>();
   ```

   **Nota:** Los servicios deben configurarse antes de llamar a `builder.Build()`.
4. Verifica que Visual Studio haya agregado al inicio de `Program.cs`:

   ```csharp
   using PollBall.Services;
   ```
5. Selecciona:

   ```csharp
   await context.Response.WriteAsync("This text was generated by the app.Run middleware.");
   ```
6. Reemplaza la selección por:

   ```csharp
   await context.Response.WriteAsync("This text was generated by the app.Run middleware. wwwroot folder path: " + builder.Environment.WebRootPath);
   ```
7. Localiza:

   ```csharp
   app.Use(async (context, next) =>
   ```
8. Antes de esa instrucción, agrega:

   ```csharp
   using (var serviceScope = app.Services.CreateScope())
   {
       var services = serviceScope.ServiceProvider;
       var pollResults = services.GetRequiredService<IPollResultsService>();
   ```
9. Después de la línea `});` que termina el bloque `app.Use`, agrega una llave de cierre `}` en una nueva línea.
10. Localiza:

    ```csharp
    string selectedValue = context.Request.Query["favorite"];
    ```
11. Al final de esa línea, presiona **Enter** y agrega:

    ```csharp
    SelectedGame selectedGame = (SelectedGame)Enum.Parse(typeof(SelectedGame), selectedValue, true);
    pollResults.AddVote(selectedGame);
    ```
12. Selecciona:

    ```csharp
    await context.Response.WriteAsync("Selected value is: " + selectedValue);
    ```
13. Reemplaza la selección por:

    ```csharp
    SortedDictionary<SelectedGame, int> gameVotes = pollResults.GetVoteResult();
    foreach (KeyValuePair<SelectedGame, int> currentVote in gameVotes)
    {
        await context.Response.WriteAsync($"<div> Game name: {currentVote.Key}. Votes: {currentVote.Value} </div>");
    ```

### Tarea 4: Ejecutar la aplicación

## Ejercicio 4: Inyectar un servicio en un controlador

### Tarea 4: Usar inyección de dependencias en el controlador

1. En **Solution Explorer**, abre `Program.cs`.
2. Selecciona:

   ```csharp
   SortedDictionary<SelectedGame, int> gameVotes = pollResults.GetVoteResult();

   foreach (KeyValuePair<SelectedGame, int> currentVote in gameVotes)
   {
   ```


   ```csharp

   {
   ```

   ```csharp

   ```


9. En `HomeController.cs`, selecciona:
